# Mifluent

**Read [AGENTS.md](AGENTS.md) before making any change.** It is the single source
of truth for the rules in this repository, and it is binding.

It in turn requires two documents, both of which must be read before writing
code:

- [docs/code-style.md](docs/code-style.md) — how code is written here
- [docs/security.md](docs/security.md) — rules that must hold in every change

Do not duplicate rules into this file. One copy, in `AGENTS.md`, or the copies
drift apart and assistants start following different versions.
